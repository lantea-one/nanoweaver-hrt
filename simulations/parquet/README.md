# Parquet Trajectory Storage Directory
====================================

This directory contains columnar Apache Parquet (`.parquet`) files generated by the .NET 10 SIMD trajectory parsing pipeline.

### Querying with pg_duckdb

When the storage infrastructure is running (`docker compose -f docker-compose.yml -f docker-compose.infra.yml up -d`), you can connect to PostgreSQL on port 5432 and execute DuckDB analytical queries directly over these files:

```sql
-- Read all trajectory frames
SELECT * FROM read_parquet('/workspace/parquet/*.parquet');

-- Calculate average atomic displacement by region
SELECT target_region, AVG(distance_from_center) AS avg_radial_distance
FROM read_parquet('/workspace/parquet/*.parquet')
GROUP BY target_region;
```
