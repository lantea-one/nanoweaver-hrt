## Exact Implementation Changes

### 1. `src/NanoWeaverHrt/Database/Migrations/Migration010_EncryptPatientDnaPhi.cs`

Modeled directly on `Migration006_EncryptGenderIdentity.cs`:
- `Table = "weaver_patient_dna_records"`
- `KeyColumn = "id"`
- `Columns = ["regimen", "notes"]`
- `GetSql(string dialect)`:
  - For PostgreSQL (`dialect.StartsWith("postgres", StringComparison.OrdinalIgnoreCase)`):
    ```sql
    ALTER TABLE weaver_patient_dna_records ALTER COLUMN regimen TYPE TEXT;
    ```
  - For SQLite: `string.Empty`.
- `UpAsync`:
  - Call `await base.UpAsync(connection, transaction, dialect, ct);`
  - Select `SELECT id, regimen, notes FROM weaver_patient_dna_records` and for each row where `regimen` or `notes` is non-null, non-empty, and `!ProfileDataProtector.IsCurrentVersionEnvelope(val)`, seal with `_protector.EncryptField(val)` (throwing `InvalidOperationException` if `_protector == null` when a plaintext row exists) and `UPDATE weaver_patient_dna_records SET regimen = @p0, notes = @p1 WHERE id = @key`.

### 2. `src/NanoWeaverHrt/Storage/PatientDnaRepository.cs`

1. Constructor:
   ```csharp
   public PatientDnaRepository(IWeaverDbConnectionFactory connectionFactory, ProfileDataProtector protector)
   {
       _connectionFactory = connectionFactory ?? throw new ArgumentNullException(nameof(connectionFactory));
       _protector = protector ?? throw new ArgumentNullException(nameof(protector));
   }
   ```
2. In `UpsertDnaRecordAsync`:
   ```csharp
   string encryptedRegimen = _protector.EncryptField(record.Regimen.ToString())!;
   string? encryptedNotes = string.IsNullOrEmpty(record.Notes) ? record.Notes : _protector.EncryptField(record.Notes);
   ...
   WeaverDbParameters.Add(cmd, "@reg", encryptedRegimen);
   ...
   WeaverDbParameters.AddNullable(cmd, "@not", encryptedNotes);
   ```
3. In `MapDnaRecordFromReader(DbDataReader reader)` (change from `private static` to `private` instance method using `_protector`):
   ```csharp
   string rawRegimen = _protector.DecryptDataUri(reader.GetString(3)) ?? string.Empty;
   if (!Enum.TryParse<TherapeuticRegimen>(rawRegimen, ignoreCase: true, out TherapeuticRegimen parsedRegimen))
   {
       parsedRegimen = TherapeuticRegimen.MaleToFemale;
   }
   string? rawNotes = reader.IsDBNull(15) ? null : reader.GetString(15);
   string? decryptedNotes = string.IsNullOrEmpty(rawNotes) ? rawNotes : _protector.DecryptDataUri(rawNotes);
   ```
