### 2. `IAuditLedgerRepository.cs` and `AuditLedgerRepository.cs`

```csharp
namespace NanoWeaverHrt.Compliance;

/// <summary>
/// Persistence contract for the FDA 21 CFR Part 11 append-only cryptographic audit ledger.
/// </summary>
public interface IAuditLedgerRepository
{
    /// <summary>
    /// Loads all committed audit records ordered by ascending <see cref="AuditRecord.SequenceNumber"/>.
    /// </summary>
    /// <returns>The ordered list of persisted <see cref="AuditRecord"/> entries.</returns>
    IReadOnlyList<AuditRecord> LoadAll();

    /// <summary>
    /// Appends a single <see cref="AuditRecord"/> to the persistent store if its sequence number is not already present.
    /// </summary>
    /// <param name="record">The signed audit record to persist.</param>
    void Append(AuditRecord record);
}
```

In `AuditLedgerRepository`:
- Inject `IWeaverDbConnectionFactory connectionFactory`.
- In `LoadAll()`, open a session via `_connectionFactory.OpenAsync(CancellationToken.None).GetAwaiter().GetResult()`, execute:
  ```sql
  SELECT sequence_number, timestamp_utc, previous_hash, current_hash,
         operator_id, action, resource, details_json,
         signature_algorithm, signer_key_id, signature_base64, signed_at_utc
  FROM weaver_audit_ledger
  ORDER BY sequence_number ASC;
  ```
  Map each row using `reader.GetInt64(0)`, `WeaverDbValues.ReadTimestamp(reader, 1)`, `reader.GetString(2..10)`, `WeaverDbValues.ReadTimestamp(reader, 11)`.
- In `Append(AuditRecord record)`, execute:
  ```sql
  INSERT INTO weaver_audit_ledger (
      sequence_number, timestamp_utc, previous_hash, current_hash,
      operator_id, action, resource, details_json,
      signature_algorithm, signer_key_id, signature_base64, signed_at_utc
  ) VALUES (
      @seq, @ts, @prev, @curr,
      @op, @act, @res, @det,
      @alg, @kid, @sig, @sts
  )
  ON CONFLICT (sequence_number) DO NOTHING;
  ```
  Bind timestamps using `session.Dialect.TimestampValue(record.TimestampUtc)` and `session.Dialect.TimestampValue(record.Signature.SignedAtUtc)`.

### 3. `ComplianceAuditService.cs`

Update constructor signature:
```csharp
    public ComplianceAuditService(
        IKeyManagementService keyManagement,
        IPostQuantumCryptoProvider cryptoProvider,
        IInternalEventBus? eventBus = null,
        IAuditLedgerRepository? repository = null)
```
Inside `lock (_ledgerLock)` in the constructor:
1. If `_repository != null`, call `IReadOnlyList<AuditRecord> existing = _repository.LoadAll();` and if `existing.Count > 0`, `_records.AddRange(existing); return;`.
2. Otherwise, create the Genesis record (`SequenceNumber = 0`) as today, add it to `_records`, and call `_repository?.Append(genesisRecord);`.
3. Inside `LogAction`, right after `_records.Add(record);`, call `_repository?.Append(record);`.
